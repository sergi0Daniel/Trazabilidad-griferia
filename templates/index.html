Campos recomendados

El sistema intenta reconocer encabezados equivalentes en español o inglés.

referencia
Referencia del producto

Campo obligatorio. No uses una ubicación como referencia.

fecha_hora
Fecha y hora del evento

Permite ordenar los eventos cronológicamente.

evento
Evento o movimiento

Describe la etapa registrada en el proceso.

ubicacion
Ubicación

Ubicación o zona del registro; puede quedar vacía si la fuente no la aporta.

sistema
Fuente del registro

Usa WMS o SAP si el archivo identifica esa procedencia.

identificador
Identificador adicional

Pedido, entrega, caja u otro ID confirmado por el área operativa.

novedad
Novedad u observación

Texto visible para que el responsable realice la revisión necesaria.
